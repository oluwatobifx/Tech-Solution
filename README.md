# TechSolutions

A concept website for **TechSolutions**, a digital growth platform that helps small and growing businesses go online, advertise, track their sales and connect with importers and exporters.

Designed and built by [Oluwatobi Joel](https://tobi-portfolio-murex.vercel.app).

## Pages

| Page | URL | What it does |
|---|---|---|
| Home | `/` | Hero with a live dashboard on a laptop, services, how it works, pricing |
| Services | `/services` | Online store, marketing & ads, sales tracking, import/export network, maps & visibility, payments, FAQ |
| Partners | `/partners` | B2B directory of importers & exporters: search and filter by sector, country and trade type, physical address with map link, website, partnership requests, and a form to list your own business |
| Dashboard | `/dashboard` | Record sales and see total revenue, a 14-day chart, sales by channel, top products, and a transactions table with CSV export |
| About | `/about` | Story and values |
| Contact | `/contact` | Contact form (demo) |

## Files

`styles.css` (all styles), `data.js` (sample partners, sales data, helpers), `app.js` (page behaviour), plus one HTML file per page. Plain HTML, CSS and JavaScript with no build step, and it's fully responsive.

It's a demo: listings, partnership requests and sales are saved in the visitor's browser (localStorage), and businesses in the directory are fictional samples.
